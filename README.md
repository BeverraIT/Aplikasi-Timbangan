# Aplikasi-Timbangan
Dashboard UI Timbangan untuk konversi output dari Perangkat Timbangan Ke System 



Cara Penggunaan:

copy perintah ini cd C:\Users\Sakti\.gemini\antigravity\scratch\scale-web-app, lalu buka terminal (cmd/powershell), lalu paste kan, kemudian:
# 1. Install semua alat database baru yang baru saja ditambahkan
npm.cmd install
# 2. Jalankan Server Database DAN Aplikasi Web secara bersamaan
npm.cmd start
